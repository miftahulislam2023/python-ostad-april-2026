## Set এর বৈশিষ্ট্য
1. Set এর সকল value unique বা অনন্য বা আলাদা হতে হবে
2. Duplication allowed কিন্তু **লাভ নাই**

```
Mathematical Set Operations

A = {
    1, 2, 3, 4, 5
}

B = {
    3, 4, 5
}

C = {
    1, 3, 5, 7
}

A u B = { 1, 2, 3, 4, 5 }
A n B = { 3, 4, 5}
A - B = A \ B = { 1, 2 }
B - A = B \ A = { } -> Null set -> ফাঁকা সেট
C - B = { 1, 7 }
B - C = { 4 }

```
